## pass and cost rules (written before the results they judge)
# Pass rule, written before any chi2 of this round (2026-11-25)
chi2: in-model vprof chi2 (P7, tag 1, cat 1 = all columns), mean over hours 12-24 (vsum.py chi2all); limit 31.
A cell (setting x test) passes when all 3 seeds are below 31 AND worst + spread <= 31,
  spread = max - min of the 3 seeds of that same cell (the "seed-to-seed spread").
Sensitivity column only (does not change verdicts): worst + pooled seed SD of that test (over all
  N2-candidate cells of this round) <= 31.
"A1 fails GOTM" (trigger for A3) and "f = 0.05 fails anything" (trigger for f = 0.04) use this same rule.
"Better floor setting from A" (for B): the cheaper passing one (higher floors = fewer calls);
  if none passes, the one with the smallest max over tests of (worst + spread).
Pick: the cheapest setting run (largest f, highest floors) with every test passing AND walk-only cost
  (calls per step x fitted us per call) <= 2x S on the reproducer and on the particle-heavy GOTM case.

# Cost rule, added after the A/B chi2 and call counts, before any timing result (timing block started)
Primary walk-only ratio = (median user of the setting - fixed) / (median user of S - fixed), where
  fixed = median user of N2 + LGR_DBG_KCONST=0.01 on the same case (1 walk call per particle step,
  so it measures everything but the walk), 3 sequential rounds, runs above load 8 discarded.
Cross-check = calls per step x per-call cost from the joint least-squares fit of the reproducer runs
  (one intercept, one slope for the N2 family N2/A1/B07/A3, one for the S family S/Sdt5/Sdt2), and in
  the heavy case the in-situ N2 line (N2 to B07).
If the primary and the cross-check land on opposite sides of 2.0, the cost condition is reported as unresolved.
